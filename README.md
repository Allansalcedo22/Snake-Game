# 🐍 Classic Java Snake Game

A classic retro 2D Snake game built in Java using Java Swing/AWT and Object-Oriented Programming principles. Developed using IntelliJ IDEA.

---

## 🎮 How to Play

* Use the **Arrow Keys** (or **WASD**) to steer the snake.
* Eat the red food squares to grow longer and increase your score.
* Avoid running into the screen borders or your own body.
* If you hit a wall or yourself, it's **Game Over**!

---

## 💻 How to Run in IntelliJ IDEA

1. **Clone or Download** this project to your computer.
2. Open **IntelliJ IDEA**.
3. Select **File > Open...** and choose the project folder.
4. Open your main class (e.g., `Main.java` or `SnakeGame.java`).
5. Click the green **Run** arrow at the top right (or press `Shift + F10`).
